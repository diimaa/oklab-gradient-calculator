# Калькулятор градиентов из двух цветов
Задача: ввести два цвета — начальный и конечный — и получить:
- подобранные хромо-цвета для получения равномерного («красивого») градиента без gamma-искажений sRGB-пространства с использованием промежуточного перевода цветов в Oklab;
- посчитать число уникальных цветов в получившемся градиенте;
- вывести список всех промежуточный цветов градиента.

Зачем?
- Работать с градиентными заливками на LED-экранах высокого разрешения (4K и более) и большого размера (10 метров в ширину и более).
- Не допустить «грязных» оттенков в градиенте.
- Подготовить данные о цветах для использования плагина (для Pixso), который сделает столько фреймов сколько полутися цветомв ивпокрасит каждый в свой цвет.

## Как работает
- Пользователь вводит два шестнадцатеричных значения цвета в формате #RRGGBB (регистр не важен).
- Интерфейс сразу обновляет фон предварительного просмотра с линейным градиентом между стартовым и конечным цветом.
- Количество уникальных оттенков считается по формуле N=max(∣ΔR∣,∣ΔG∣,∣ΔB∣)+1, где ΔR, ΔG, ΔB — разница каналов между конечным и начальным цветами (0–255).
- Интерполяция строится в пространстве Oklab с использованием матриц M₁ и M₂ из статьи «From personal project to industry standard» (Björn Ottosson). Это дает более равномерные переходы между оттенками по восприятию.
- Количество промежуточных точек автоматически ограничено восемью, при этом список (цвет и позиция 0–100%) показывается под предпросмотром через запятую.
- Расчет числа уникальных оттенков основан на максимальной компонентной разнице (считается по формуле N=max(∣ΔR∣,∣ΔG∣,∣ΔB∣)+1, где ΔR, ΔG, ΔB — разница каналов между конечным и начальным цветами [0–255]).

## Как применять результат
- Число цветов в градиенте поможет оценить число переходов во времени (пока нельзя рассказывать зачем это все сделано, позже объясню).
- Список цветов нужен для работы плагина Pixso и запуска программы для Processign (Java), который по списку нарисует нужное число фреймов, каждый заполнен нужным цветом, и текст для маски (ну, надо мне такое, не могу пока сказать зачем).
- Размер фрейма выставлен в 1×64 пикселя, но размер можно поменять в mail.js — первые три строки: ширина, высота и расстояние между фреймами (default: 1, 64, 0).
- Полусится линейка фреймов, которая нарисует градиент.
- Дальше фреймы можно поместить в Auto Layout и изменить им размер на нужный в маштабе. Экспортировать в растовые картинки и применять где требуется.
